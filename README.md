# Gia Huy Thai — Academic Homepage

Personal academic portfolio built with [academic-homepage](https://github.com/luost26/academic-homepage), a Jekyll template released under the MIT License.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open the local URL shown by Jekyll.

## Deployment

This repository is intended to be published as the GitHub Pages user site:

```text
https://oxyzgiahuy.github.io
```

The original template attribution and `LICENSE` file are retained.
